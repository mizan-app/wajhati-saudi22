# وجهتي السعودية — Dalili Tourism

موقع سياحي تجريبي باللغة العربية (RTL) مبني باستخدام HTML وCSS وJavaScript.

## تشغيل الموقع
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث.
3. يلزم الاتصال بالإنترنت لعرض الخطوط والصور الخارجية.

## الملفات
- `index.html`: أقسام الموقع والنماذج.
- `style.css`: التصميم المتجاوب للجوال والكمبيوتر.
- `script.js`: قائمة الجوال، البحث والتصفية، المفضلة والتحقق من النماذج.

## التفاعلات المتاحة
- تصفية الوجهات حسب المدينة ونوع التجربة.
- تصفية الأماكن السياحية حسب التصنيف.
- زر مفضلة تجريبي يعمل خلال الجلسة فقط.
- نموذج تخطيط رحلة مع التحقق من الحقول وتاريخ الزيارة.
- نموذج تواصل مع تحقق من البيانات.

## ملاحظات مهمة
- هذا نموذج واجهة أمامية فقط. لا توجد قاعدة بيانات أو إرسال فعلي للنماذج أو نظام حجوزات.
- لتفعيل الحجز والتواصل فعليًا، اربط النماذج بخادم أو خدمة نماذج موثوقة، مع سياسة خصوصية وحماية مناسبة للبيانات.
- أسماء الفعاليات والأماكن والأوصاف والصور أمثلة إرشادية؛ راجع المصادر الرسمية للتحقق من المعلومات والمواعيد.
- الصور والخطوط مستضافة على خدمات خارجية، لذا تحتاج اتصالًا بالإنترنت وقد تتغير روابطها.
- صور الموقع مستخدمة لأغراض نموذج التصميم؛ استبدلها بصور مناسبة ومرخّصة قبل النشر العام.
